FILES

- images/: profile, plant/laboratory visuals and individual equipment tiles
- Ahmad_Nawaz_CV.pdf: original CV supplied for this project

PUBLISH ON GITHUB PAGES
1. Extract this ZIP file.
2. Create or open a GitHub repository for the portfolio.
3. Upload the contents of this folder (index.html, images folder, and Ahmad_Nawaz_CV.pdf) to the repository root.
4. Open Settings > Pages. Select Deploy from a branch, choose main and /(root), then Save.
5. Wait for deployment and open the GitHub Pages URL shown in Settings > Pages.
